# BrownTechnology Enterprise Cybersecurity Homelab
## Overview
Welcome to the BrownTechnology Enterprise Cybersecurity Homelab. 
This repository documents my hands-on experience building and administering an enterprise cybersecurity environment using industry-standard technologies. The lab is designed to develop practical skills in Linux administration, enterprise networking, virtualization, firewall management, security monitoring, SIEM engineering, packet analysis, Bash scripting, and blue team operations.
Each project is built from the ground up, no tutorials to strengthen my understanding of how enterprise systems are deployed, secured, monitored, and maintained. Every installation, configuration, troubleshooting process, and security concept is documented to demonstrate both technical knowledge and professional documentation skills. 
The technologies and projects within this repository are selected to reflect the types of skills used in enterprise cybersecurity environments, including Security Operations Center, systems administration, network security, and detection engineering.

### Purpose 
The purpose of this homelab is to gain hands-on experience with enterprise cybersecurity technologies by building, configuring, troubleshooting, and documenting a realistic lab environment. Rather than relying solely on certifications or theoretical knowledge, this repository demonstrates practical experience through completed projects and continuous learning. As additional technologies are deployed, this repository will continue to expand with new documentation, configurations, troubleshooting guides, and security projects.
