# BrownTechnology Enterprise Cybersecurity Homelab Roadmap
## Purpose
This roadmap outlines the planned growth of the BrownTechnology Enterprise Cybersecurity Homelab.
The goal is to progressively build an enterprise environment while developing practical experience with Linux administration, enterprise networking, firewall management, SIEM engineering, Windows administration, Active Directory, detection engineering, incident response, and security monitoring. 
Each phase will be built upon the previous one to eventually develop a complete mastery and strong understanding of how enterprise systems are deployed, secured, monitored, and maintained. 
### Long-Term Goal
Build a complete enterprise cybersecurity environment capable of supporting:
- Linux Administration
- Windows Administration
- Enterprise Networking
- Firewall Management
- Packet Analysis
- Splunk
- SIEM & Security Monitoring
- Active Directory
- Detection Engineering
- Incident Response
- Blue Team Operations
- Automation with Bash and Python
- Enterprise Documentation
