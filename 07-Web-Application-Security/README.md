# Web Application Security Lab
## Overview
This section documents the deployment of an intentionally vulnerable web application environment used to develop and demonstrate hands-on web application security skills. 
The lab uses Docker to deploy OWASP Juice Shop on an Ubuntu Server. The environment will be used for controlled security testing, traffic analysis, vulnerability identification, and future Burp Suite testing. 
### Current Environment
- Ubuntu Server
- Docker Engine
- OWASP Juice Shop
- TCP Port 30000
