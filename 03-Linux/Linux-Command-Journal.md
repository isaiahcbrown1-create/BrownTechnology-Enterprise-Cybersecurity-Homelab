# Overview
This journal documents the Linux commands I have learned and will continue to grow as I learn and master more commands. 

## Purpose
The purpose is to create a personal reference that explains each command and when it should be used, and how it contributes to managing Linux systems.
### Current Status
This journal will continue to grow. 

#### Commands
pwd- displays the current working directory. This should be used to find out exactly where you are in the system.
ls- lists the contents of a directory. This should be used to view the contents of files and directories.
cd- ex: cd Documents. This changes the current directory to another directory quickly.
mkdir- ex: mkdir Projects. This used to organize files, scripts, logs, and project directories.
touch- ex: touch notes.txt. This command creates a new empty file.
cp- ex: cp file1.txt backup.txt. This command is used to create backups by copying the files of one to another before modifying important files.
mv- ex: mv old.txt new.txt. This moves or renames files and directories to organize them.
rm- ex: rm file.txt. This is used to delete files and directories.
cat- ex: cat notes.txt. Displays the contents of a file.
nano- ex: nano notes.txt. Used to edit files directly from the terminal.
echo- ex: echo "Hello World". Transfers text or writing into a file.
find- ex: find -name notes.txt. This searches your system for a specific file or directory.
chmod- ex: chmod 755 script.sh. This controls who can read, write, or execute files and monitors permissions.
man- ex: man ls. Displays the manual page for commands.
ssh- ex: ssh user@hostname. This connects securely to remote systems from your own system.
apt update- ex: sudo apt update. Makes sure that the system has the latest package information before installing or updating software.
apt upgrade- ex: sudo apt upgrade. Installs available software updates.
