# Oracle VirtualBox & Enterprise Virtualization
## Overview
Enterprise virtualization is the foundation of modern infrastructure. It allows multiple operating systems, servers, and security appliances to run on a single physical computer. This section documents the deployment and configuration of Oracle VirtualBox as the virtualization platform used to build the BrownTechnology Enterprise Cybersecurity Homelab.
